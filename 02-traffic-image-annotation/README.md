# Traffic Image Annotation Project

## Project Overview
This project demonstrates my practical experience with image annotation using CVAT. I manually annotated objects in a street traffic image to create labeled data for computer vision.

## Project Details
- **Annotation tool:** CVAT
- **Annotation method:** Bounding boxes
- **Object classes:** Car, Bus, Person
- **Total annotations:** 31
- **Dataset format:** COCO 1.0
- **Image source:** Pexels

## Skills Demonstrated
- Identifying objects in complex traffic scenes
- Drawing bounding boxes around vehicles and pedestrians
- Assigning the correct object labels
- Managing annotation tasks in CVAT
- Exporting annotations in COCO format

## Project Files
The COCO annotation ZIP contains the exported annotation data.

## Project Purpose
This project was created as part of my data annotation portfolio to demonstrate skills relevant to AI training and computer vision data labeling.
